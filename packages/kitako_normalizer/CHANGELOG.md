## 0.1.0

* Initial implementation of TaglishNormalizer
* Features:
  - Dictionary-based abbreviation expansion (80+ mappings)
  - Taglish verb pattern handling (nag- + English verb)
  - Reduplication preservation (30+ allowed patterns)
  - Character normalization (repeated chars, punctuation)
  - Tokenizer utilities (tokenize, detokenize, isPunctuation)
* NormalizerService wrapper for app integration
* Comprehensive test suite
